# IDOA-IoT-Anomaly-Detection

This repository will provide the MATLAB implementation and experimental configurations for the paper:

**An Improved Dream Optimization Algorithm-Driven Feature Selection Model for IoT Traffic Anomaly Detection**

The source code, parameter settings, and experimental scripts will be made publicly available upon acceptance.

## Dataset

The experiments are based on publicly available datasets:

- UCI Machine Learning Repository datasets
- NF-ToN-IoT-v2 dataset: https://espace.library.uq.edu.au/view/UQ:38a2d07
